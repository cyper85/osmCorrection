osmCorrection ist ein rein privates Projekt ohne Gewinnabsicht. Es gibt keine Werbung, kein Tracking und keine kostenpflichtigen Angebote.

Kartendaten

Karte und Daten stammen aus OpenStreetMap: © OpenStreetMap-Mitwirkende, verfügbar unter der Open Database License (ODbL). osmCorrection ist ein unabhängiges Projekt und wird nicht von der OpenStreetMap Foundation betrieben.

Änderungen, die du hochlädst, werden mit deinem eigenen OSM-Konto gespeichert und von dir verantwortet.

Quellcode

Der Quellcode ist offen und steht unter der MIT-Lizenz:

  • osmCorrection: die Anwendung
  • osmValidation: die Prüfregeln für Tag-Werte
  • osmAssist: die KI-Auswertung von Websites

Fehler und Vorschläge gern als Issue auf GitHub.

Werkzeuge

  • Entwicklungsumgebung: PhpStorm von JetBrains
  • KI: Claude Code von Anthropic mit Claude Opus 5.5. Die KI hat beim Programmieren und Schreiben der Texte geholfen; geprüft und verantwortet wird alles vom Anbieter.
  • Hosting und Build: GitHub Pages und GitHub Actions, Aktualisierung der Abhängigkeiten mit Renovate
  • Bibliotheken: Vite, TypeScript, Leaflet, osm-auth, opening_hours.js, libphonenumber-js, Anthropic TypeScript SDK, Vitest, Playwright
  • Dienste: OpenStreetMap-API, Overpass API, Nominatim, Wikidata und, wenn du es nutzt, die Claude API
